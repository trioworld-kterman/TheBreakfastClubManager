# i18n Design: Danish/English Language Support

**Date:** 2026-05-19
**Status:** Approved

## Goal

Add English language support alongside existing Danish, with a manual DA/EN toggle in the UI. Language preference persists in localStorage.

## Approach

Simple `t(key, lang)` function — no external libraries. Two typed translation objects (`da`, `en`) in a single file. Language state at App.tsx level, passed as prop.

## Architecture

### `utils/i18n.ts`
- `Translations` interface — all translation keys typed
- `da` and `en` objects implementing `Translations`
- `Language = 'da' | 'en'` type export
- `t(key: keyof Translations, lang: Language): string` export

### Language state
- Lives in `App.tsx` via `useState<Language>`
- Initialized: `localStorage.getItem('lang') as Language ?? 'da'`
- On toggle: update state + `localStorage.setItem('lang', newLang)`
- Passed as `lang` prop to `Dashboard` and `LoginView`

### Toggle UI
- `DA | EN` segmented control in Dashboard header (next to "Log ud")
- Same visual style as bread roll 1/2 selector
- Also available on LoginView (top-right corner)

## Scope

**Translated (all user-visible strings):**
- `Dashboard.tsx` — section headers, labels, button text, confirmation dialogs, empty states, badge text
- `LoginView.tsx` — form labels, placeholder text, button text, instructions

**Not translated:**
- Group names (user data)
- Employee names (user data)
- `console.error` messages
- Commit messages / code comments

## Key Translation Keys (examples)

```ts
interface Translations {
  // Dashboard
  synced: string;
  syncedSubtitle: string;
  logout: string;
  teamHeader: string;
  addPlaceholder: string;
  addButton: string;
  markAttendance: string;
  dragHint: string;
  planHeader: string;
  attendeeSummary: (count: number, rolls: number) => string;
  noAttendees: string;
  buyRolls: (count: number) => string;
  thisFriday: string;
  upcoming: string;
  emptySlot: string;
  deleteConfirm: (name: string) => string;
  // LoginView
  loginTitle: string;
  loginSubtitle: string;
  groupKeyLabel: string;
  groupKeyPlaceholder: string;
  groupNameLabel: string;
  groupNamePlaceholder: string;
  loginButton: string;
}
```

Note: some keys are functions (accept count/name) to handle pluralization and interpolation without a library.
