# i18n: Danish/English Language Support Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add English language support with a DA/EN toggle button in the UI; preference persists in localStorage.

**Architecture:** Single `utils/i18n.ts` file with typed `da` and `en` translation objects and a `getT(lang)` function. Language state lives in `App.tsx`, passed as `lang` + `onLangChange` props to `LoginView` and `Dashboard`. No external libraries.

**Tech Stack:** React 19, TypeScript 5.8 — files live at repo root (not `src/`): `App.tsx`, `components/Dashboard.tsx`, `components/LoginView.tsx`, `utils/i18n.ts` (new), `types.ts`

### Task 2: Add language state to App.tsx and wire props

**Files:**

**Context:** `App.tsx` manages all global state. Add `lang` + `setLang` here, initialize from localStorage, persist on change. Pass `lang` + `onLangChange` to `LoginView` and `Dashboard`.

**Step 1: Read `App.tsx`** (absolute path: `C:\kode\TheBreakfastClubManager\App.tsx`)

**Step 2: Add import at top**

Add after existing imports:
```ts
import { Language, LANG_STORAGE_KEY, getT } from './utils/i18n';
```

**Step 3: Add language state inside `App` component** (after existing `useState` declarations)

```ts
const [lang, setLang] = useState<Language>(
  () => (localStorage.getItem(LANG_STORAGE_KEY) as Language) ?? 'da'
);

const handleLangChange = (newLang: Language) => {
  setLang(newLang);
  localStorage.setItem(LANG_STORAGE_KEY, newLang);
};
```

**Step 4: Update loading screen** to use translation

Find:

```tsx
<h2 className="text-2xl font-serif font-black text-amber-950">{getT(lang).loading}</h2>
```

```tsx
if (!groupKey) return <LoginView onLogin={handleLogin} />;
```

Replace with:
